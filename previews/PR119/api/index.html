LegendDSP.LegendDSP — Module
LegendDSP

Digital signal processing for LEGEND waveforms.

The package provides

  • DSP chains that reduce tables of waveforms to tables of waveform parameters: dsp_icpc for HPGe detectors, dsp_puls for pulser channels, dsp_aux for auxiliary channels, dsp_sipm for SiPMs and dsp_pmts for PMTs, each with a _compressed variant where compressed data exists;
  • grid scans over filter parameters (dsp_*_optimization) that provide the input for choosing optimal filter settings;
  • functions for single waveform parameters (get_t0, get_threshold, get_a, get_qdrift, get_lq, get_triggers) and waveform statistics (tailstats, extremestats, thresholdstats, saturation);
  • filters for RadiationDetectorDSP.jl waveforms, such as MovingWindowMultiFilter, WeightedSavitzkyGolayFilter and HaarAveragingFilter;
  • support-vector-machine quality cuts (get_qc_ml_func, get_qc_classifier);
  • the configuration type DSPConfig.

All time-valued fields are Unitful quantities. Create an instance from DSP metadata with DSPConfig(pd::PropDict).

Create a DSPConfig{Float64} from DSP metadata.

struct DerivativeFilter{T<:RealQuantity} <: AbstractRadIIRFilter

Backward difference of a signal: y[i] = gain * (x[i] - x[i-1]), and y[1] = gain * (x[2] - x[1]) for the first sample.

The difference is not divided by the sampling step, so the result is the change per sample times gain. The time axis is not changed.

LegendDSP.HaarAveragingFilter — Type
struct HaarAveragingFilter <: AbstractRadSigFilter{LinearFiltering}

Haar averaging filter: sums each pair of adjacent samples, scales the sum by 1/√2 and keeps every down_sampling_rate-th result.

With down_sampling_rate = 2 the pairs do not overlap, which corresponds to the approximation step of a discrete Haar wavelet transform. The output has ceil(n / down_sampling_rate) samples for n input samples and the output time axis consists of every down_sampling_rate-th element of the input time axis. Sample indices beyond the signal are clamped to the first and last sample.

LegendDSP.IntersectMaximum — Type
struct IntersectMaximum{T<:RealQuantity} <: Function

Find the up-crossings of a signal through a threshold and the maximum following each of them.

An up-crossing is a position where the signal rises to the threshold and stays at or above it for at least mintot. A crossing at the first sample is not counted. The crossing time is interpolated linearly.

Call an instance as

(f::IntersectMaximum)(signal::SamplesOrWaveform, threshold::RealQuantity)

It returns a named tuple. All entries except multiplicity are vectors with one element per up-crossing:

  • x: crossing time
  • x_high: time at which the signal falls below the threshold again (interpolated linearly), or the last time of the signal if it does not
  • x_tot: x_high - x
  • max: maximum of the signal within maxtot after the crossing, interpolated by a parabola if it is an interior sample
  • multiplicity: number of up-crossings

mintot and maxtot are converted to numbers of samples using the step of the time axis. For a time axis with a unit they need to be quantities of the same dimension; the defaults of 4 and 100 are plain numbers.

Constructors:

Fields:

  • mintot::Union{Real, Unitful.AbstractQuantity{<:Real}}: minimum time-over-threshold

  • maxtot::Union{Real, Unitful.AbstractQuantity{<:Real}}: maximum time-over-threshold for max to appear

struct ModifiedSincFilter{T<:RealQuantity} <: AbstractRadFIRFilter

A Modified-Sinc filter.

The kernel is a windowed sinc function with a half-width of m; the degree d determines the number of extrema in the kernel. At the signal boundaries the signal is extended by weighted linear extrapolation. d has to be even and in 2:10, and m has to be at least d/2 + 2 samples; otherwise an AssertionError is thrown.

signal = vcat(zeros(n), 10*ones(n)) + (noise*rand(2*n) .- noise/2)
wf = RDWaveform(t, signal)

# define filter parameters and filter
flt = ModifiedSincFilter(d=4, m=1u"μs")

# apply filter to signal
wf_new = flt(wf)

LegendDSP.MovingWindowFilter — Type
struct MovingWindowFilter{T<:RealQuantity} <: AbstractRadFIRFilter

Causal moving average of a signal over a window of length.

With the window length l in samples (length divided by the step of the time axis, rounded) and L samples, the output is

y₁ = x₁
yₙ = yₙ₋₁ + (xₙ - x₁)/l,       for n ∈ {2, …, l}
yₙ = yₙ₋₁ + (xₙ - xₙ₋ₗ)/l,     for n ∈ {l+1, …, L}

which equals a moving average over the l latest samples with the signal extended to the left by its first sample. The time axis is not changed.

Working example:

using RadiationDetectorSignals
using Unitful

signal = rand(100)
t = range(0u"ms", 20u"ms", 100)

wf = RDWaveform(t, signal)
flt = MovingWindowFilter(1u"ms")
wf_new = flt(wf)

LegendDSP.MultiIntersect — Type
struct MultiIntersect{T<:RealQuantity} <: Function

Find the first times at which a signal reaches given fractions of its maximum.

For each ratio in threshold_ratios, the threshold is that ratio times the maximum of the signal. The first position where the signal stays at or above the threshold for at least mintot is refined: a polynomial of degree d is fitted to the 2n samples around it, evaluated on a grid with sampling_rate times as many points, and searched for the threshold crossing. The thresholds are searched in the order given, each starting at the position found for the previous one, so the ratios should be ascending. An AssertionError is thrown if the fit window would reach beyond the signal.

Call an instance as

(f::MultiIntersect)(signal::SamplesOrWaveform)

It returns a vector with one crossing time per ratio, and an array of zeros for an empty signal.

mintot is converted to a number of samples using the step of the time axis. For a time axis with a unit it needs to be a quantity of the same dimension; the default of 4 is a plain number.

Fields:

  • n::Int64: half window length of polynomial fit

  • d::Int64: degree of polynomial

LegendDSP.WeightedSavitzkyGolayFilter — Type
struct WeightedSavitzkyGolayFilter{T<:RealQuantity} <: AbstractRadFIRFilter

A Weighted-Savitzky-Golay filter.

A polynomial of degree degree is fitted by weighted least squares in a window of total length length around each sample, and the fitted value is the output. The weights fall off with the distance from the window center according to weightType:

  • 0: constant weights, which gives the ordinary Savitzky-Golay filter
  • 1: Gaussian-like weights
  • 2: Hann weights, cos²
  • 3: squared Hann weights, cos⁴
  • 4: cubed Hann weights, cos⁶

The window is adapted near the boundaries of the signal. Other values of weightType raise an AssertionError, as do a signal shorter than the window and a degree larger than twice the half-window in samples.

Working example:

using RadiationDetectorSignals
using Unitful

n = 600
noise = 1.
t = range(0u"μs", 20u"μs", 2*n)
signal = vcat(zeros(n), 10*ones(n)) + (noise*rand(2*n) .- noise/2)
wf = RDWaveform(t, signal)

# define filter parameters and filter
flt = WeightedSavitzkyGolayFilter(length=1u"μs", degree=3, weightType=2)

# apply filter to signal
wf_new = flt(wf)

Fields:

  • length::Union{Real, Unitful.AbstractQuantity{<:Real}}: total filter length

LegendDSP.WhittakerHendersonFilter — Type
struct WhittakerHendersonFilter <: AbstractRadSigFilter{LinearFiltering}

A Whittaker-Henderson filter.

The output y for an input x minimizes sum((x - y).^2) + λ * sum(Δᵖy.^2), where Δᵖy are the finite differences of order p of y. It solves (I + λ DᵀD) y = x with the difference matrix D by a banded Cholesky decomposition. A larger λ gives a smoother output.

Working example:

using RadiationDetectorSignals
using Unitful

n = 600
noise = 1.
t = range(0u"μs", 20u"μs", 2*n)
signal = vcat(zeros(n), 10*ones(n)) + (noise*rand(2*n) .- noise/2)
wf = RDWaveform(t, signal)

# define filter parameters and filter
flt = WhittakerHendersonFilter(p=3, λ=4)

# apply filter to signal
wf_new = flt(wf)

Constructors:

  • WhittakerHendersonFilter(; fields...)

Fields:

  • p::Int64: highest differentiation degree

  • λ::Real: penalty strengh imposed on non-smooth functions

LegendDSP.dsp_icpc — Method
dsp_icpc(data::Table, config::DSPConfig, τ::Quantity, pars_filter::PropDict; f_evaluate_qc::Union{Function, Missing}=missing)

DSP chain for HPGe (ICPC) detector waveforms. Returns a table with one row per waveform.

The baseline is subtracted, the waveforms are pole-zero corrected with the decay time τ, and timing, energy, current, charge-drift, quality and saturation parameters are determined. Use dsp_icpc_compressed for compressed data.

Arguments

  • data: table with the input columns below; encoded columns are decoded with decode_data
  • config: DSPConfig. config.kwargs_pars needs the entries fc_bit_depth, t0_flt_pars, t0_mintot, tx_mintot, intrace_mintot, int_interpolation_order, int_interpolation_length, sig_interpolation_order and sig_interpolation_length.
  • τ: decay time of the preamplifier signal, used for the pole-zero correction
  • pars_filter: optimized filter parameters as a PropDict: trap, cusp and zac with the entries rt and ft, and sg and mwa with the entry wl. Missing entries are taken from config.default_flt_param.

Keywords

  • f_evaluate_qc: function for get_qc_classifier. With missing no classification is done and qc_label is -1.

Input columns

waveform, baseline, timestamp, eventnumber, daqenergy

Output columns

Amplitudes have the unit of the waveform samples. Times with a stated unit are converted; the others are in the unit of the waveform time axis.

Baseline and tail:

  • blmean, blsigma, blslope, bloffset: statistics of the waveform in config.bl_window
  • tailmean, tailsigma, tailslope, tailoffset: the same statistics of the pole-zero-corrected waveform in config.tail_window
  • tail_τ, tail_mean, tail_sigma: decay time, and mean and standard deviation of the logarithm of the baseline-subtracted waveform in config.tail_window, from tailstats

Timing, from the pole-zero-corrected waveform, in µs:

  • t0: start of the charge rise, from get_t0
  • t10, t50, t80, t90, t99: first times at which the waveform reaches 10%, 50%, 80%, 90% and 99% of e_101010, from get_threshold
  • t50_current: time at which the Savitzky-Golay derivative reaches half of its maximum
  • drift_time: t90 - t0, in ns

Energies, from the pole-zero-corrected waveform:

  • e_max, e_min: maximum and minimum of the baseline-subtracted waveform before the pole-zero correction
  • e_10410, e_535, e_313, e_101010: maximum after a TrapezoidalChargeFilter with rise time and flat-top time of 10 and 4 µs, 5 and 3 µs, 3 and 1 µs, and 10 and 10 µs
  • e_trap, e_cusp, e_zac: value of the trapezoidal, CUSP and ZAC filtered waveform at t50 + rt + ft/2 (trapezoidal) and t50 + flt_length/2 (CUSP and ZAC), determined by a signal estimator. rt and ft are the optimized rise and flat-top time of the respective filter in pars_filter, and flt_length is config.flt_length_cusp or config.flt_length_zac.
  • e_trap_max, e_cusp_max, e_zac_max: maximum of the filtered waveform
  • t_trap_max, t_cusp_max, t_zac_max: time of that maximum
  • e_10410_inv, e_313_inv: maximum after the e_10410 and e_313 filters of the waveform multiplied by -1
  • t0_inv: t0 of the waveform multiplied by -1, in µs, determined with the default flt_pars of get_t0

Current:

  • a_raw: maximum in config.current_window of the simple derivative (DerivativeFilter(1))
  • a_sg, t_a_sg: maximum in config.current_window of the Savitzky-Golay derivative with window length sg.wl and polynomial degree config.sg_flt_degree, and its interpolated time
  • a_mwa, t_a_mwa: maximum in config.current_window of the simple derivative after MovingWindowMultiFilter(mwa.wl; passes = config.a_mwa_passes), and its interpolated time
  • a_sg_<ns>, a_mwa_<ns>: the same maxima for each fixed window length in config.a_sg_windows and config.a_mwa_windows, with the window length in ns in the column name
